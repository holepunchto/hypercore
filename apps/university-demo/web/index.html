NO NODE.JS RUNTIME

        
01
Append an event
Create, edit or archive a project. The Rust server validates your input and appends a new event. Existing records remain unchanged.
02
Build the current view
Project cards are the current state derived from recorded events. Each edit includes an expected version to avoid silently overwriting another edit.
03
Verify the history
Audit the log or export a signed bundle. Verification checks integrity against a trusted writer key; it does not decide who should have access.

        
Try the local API
JSON / HTTP
Commands below use this server’s address. No JavaScript service is required.
GET /api/projectsList current projects
POST /api/projectsAppend a project creation
PATCH /api/projects/:idAppend a version-checked edit
POST /api/projects/:id/archiveAppend an archive event
GET /api/projects/:id/historyInspect one project’s history
POST /api/auditAudit the stored log
GET /api/exportDownload a signed replication bundle
